# Horizon Sodium 0.4.0

- Each of the eight tabs displays only its own settings.
- Scrolling, search and keyboard navigation stay inside the selected tab.
- Removed the extra spacing between Sodium/Sodium Extra headings and their first category.
- Works with the separate Continuity Horizon companion in Video Settings.

Download `sodium_horizon-0.4.0.hnmod`. Replace older Sodium bundles in `horizon-native-mods`, then rebuild native mods and restart Horizon. Do not keep multiple Sodium bundles installed.

Requires Minecraft data 26.3 and Horizon c9d474dd9116e84c243f8992d75c11314df56f06. Continuity is a separate download: https://github.com/badmasti2/continuity-horizon/releases/latest

Four focused tab/spacing tests passed, all eight tabs were opened and visually checked in an isolated game, and the combined native build passed. The renderer and native option bindings retain the prior version's behavior and limitations. See VALIDATION.md and README.md for details.
