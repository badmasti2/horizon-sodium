# Horizon Sodium 0.3.1

Sodium-style video settings and non-lighting optimizations for Horizon.

- Hover sliders and native UI clicks.
- Scrolling restricted to the options panel.
- Horizon graphics API selection.
- Render and simulation settings up to 128 chunks.

Requires Minecraft data 26.3 and Horizon `c9d474d`. Place the `.hnmod` in Horizon's native mods folder, remove older copies and rebuild native mods. Restart Horizon after changing API.

Local native compilation checks and standalone tests passed. Some controls remain read-only; full visual parity is unverified. Multiplayer chunk delivery and simulation are server-controlled.
